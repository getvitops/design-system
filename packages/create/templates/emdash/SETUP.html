4. Domain strategy

Two mutually exclusive tracks. Pick one — do not do both in the same deploy.

4a. Go live on *.workers.dev (default, safe)

Leaves any existing live site untouched at its current domain. Do this first, always — cutover is a separate, later step.

4b. Cut over to the custom domain

This step overwrites the zone's DNS record the moment you deploy — it is the one irreversible-feeling moment in this whole checklist, and it takes an existing live site down at that instant. Do it deliberately, not as part of a bigger batch of changes. It is safe to complete stage 6 (Search Console / GCP / ads) before this — vitops search setup only ever creates a verification TXT record, it never touches the apex.
