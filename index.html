Vitops · CSS framework

A small layout vocabulary you can hold in your head.

Named width tracks, container-gated utilities, relationship-based rhythm, schema-driven colour and type, and a staged animation library. Every demo below runs on the real framework CSS.

Why this exists

Applying a few well-named classes is far easier to keep consistent than configuring the same settings by hand — change the class once, every element follows.

Composing within a track

Tracks set how wide a block is; a handful of utilities set what happens inside it. All are container-gated with the same sm/md/lg/xl suffixes, so they reshape as the container grows — mobile-first, stacked by default: .flex / .flex-row / .flex-col, .split-1-2 and friends, .align-* / .justify-*, and .text-*.

04Dark mode

Named ramps never change — pine is always pine. Dark mode only remaps which step each semantic role points at, so components referencing semantic tokens (--color-surface, --color-success) adapt automatically. Bricks toggles the mode; the build emits the remapping.

Try it — this flips [data-brx-theme="dark"] on the page, exactly what the generated dark block keys off. The whole page background is itself a surface token, so it flips too:

--color-surfacesurface role
--color-success-dsuccess role
--color-brand-primary-dbrand (identity)

Watch surface and success flip in dark (they invert), while brand-primary holds steady — it has no dark remap, so it resolves the same in both modes.

05Component patterns

Interaction patterns encode the hover/active/focus behaviour once, so applying them is consistent and judgment-free. Buttons and links are styled at the element level (via zero-specificity :where(), so any class — including Bricks' own — overrides them); badges and cards are classes.

Buttons

Bare <button> defaults to primary. Role variants are a class on the element. Hover darkens a step, click presses, keyboard focus rings.

06Vertical rhythm

Put .rhythm on a container; adjacent siblings get spacing by relationship — a heading hugs its paragraph, a new section gets air. Gaps are multiples of one line (rlh), scaled by one dial:

07Animations

Effects are split by rendering stage — composite (transform/opacity), paint (filter/clip), layout (size). Click any tile to replay it:

An effect only sets --_anim + --*-from/-to vars; a driver supplies the mechanism. The tiles above use .animate-trigger (plays once when .is-active is set). The same effects also drive scroll timelines and state-flip transitions — below.

State-flip via transitions

A .transition base plus generated hover-/focus-/active-<fx> variants tween the same --<prop>-from/-to vars as the keyframes — but with a CSS transition, so they reverse cleanly. Because each variant binds one effect to one state, different effects can bind to different states on the same element (last tile). Hover the first two; click the third to toggle .is-active.
