Questions

The usual first questions.

Do we have to use Bricks?

No. The same system ships as a Tailwind v4 theme for Astro, or as a standalone CSS bundle. Bricks just gets first-class editor support.

Can our team edit pages after handover?

Yes — that's the point. Utility classes and custom Bricks elements let non-developers build on-brand pages without touching CSS.

How do you keep docs from going stale?

They're generated from the same source that builds the site, on every deploy — so the reference always matches what's live.
